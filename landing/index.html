Agentic Video Workflow

How AI Works With Video on CinemaGrid

Instead of brittle screen automation, CinemaGrid gives agents direct programmatic access to an immutable, copy-on-write editing engine. Here is the three-phase loop:

01
👁️

Perceive & Inspect

The agent inspects sequences, clips, media bins, and audio transcripts with commands like inspect sequence or transcript.inspect. Transcripts include word-level timestamps and speaker diarization generated by the integrated Whisper model.

{"method": "transcript.search", "params": {"query": "um"}}
02
🧠

Reason & Plan

The LLM reasons about rhythm, pacing, filler words, and narrative arc. Because CinemaGrid measures all edits in exact integer Tick units (254,016,000,000 per second), the agent never causes floating-point drift or desynced audio over long edits.

{"method": "transcript.removeFillers", "params": {}}
03
⚡

Act & Execute

Edits are applied as single atomic undoable steps via Session::execute(). The engine enforces all timeline invariants (no overlapping clips, track bounds). If a command is invalid, a structured error is returned instead of panicking, allowing the agent to self-correct.

{"method": "sequence.rippleDelete", "params": {"clip": 32}}
Engineering Standards

Engineered to Outperform

CinemaGrid is built on rigorous craft standards defined across the workspace crates.

RULE 0

Never Crash

No unwrap(), expect(), or panics in application code. Every hostile input (corrupt media files, invalid parameters, full disks) returns an informative Result<T, E>. Unsaved user and agent work always survives.

TIME BASE

Microsecond Exact Tick

Zero float seconds in edit math. All positions are rational integer ticks. Whether editing at 23.976 fps, 29.97 drop-frame, 60 fps, or 120 fps, timeline items and 48 kHz audio align with microsecond precision.

PERFORMANCE

Arc<Project> Snapshots

Copy-on-write project trees allow background export, preview rendering, and UI playback to read project state concurrently without locks, while the undo stack maintains instantaneous snapshot reversibility.

CODECS

Clean-Room Implementations

Zero GPL code. Codecs (H.264, HEVC, AV1, ProRes, DNxHR, APV) and containers (MP4, MKV, MXF, AVI) are implemented directly from public ITU/ISO specifications under permissive MIT/Apache-2.0 licenses.

PROTOCOL

Dual MCP & Bridge Mode

Run headlessly on a Linux server without a display (cinemagrid-cli mcp) or connect Claude directly to your live desktop editing session (--bridge 127.0.0.1:9876) to pair-program edits side-by-side.

AUDIO & AI

Embedded Neural Stack

Local AI transcription via Whisper with Voice Activity Detection, alongside built-in neural and basic formant TTS narration generators that output sample-accurate WAV clips directly onto tracks.

Get Started

Start Editing with AI in Seconds

CinemaGrid is ready to run as a desktop app, headless CLI, or MCP server. 

# 1. Build CinemaGrid engine and CLI
cargo build --release -p cinemagrid -p cinemagrid-cli

# 2. Launch the desktop app with the AI control bridge enabled
./target/release/cinemagrid --control 9876 &

# 3. Connect your AI agent via MCP or send instant commands
./target/release/cinemagrid-cli --bridge 127.0.0.1:9876 exec sequence.addEdit
./target/release/cinemagrid-cli --demo export showcase.mp4 --scale 0.5
# 1. Register CinemaGrid as an MCP server in Claude Code
claude mcp add cinemagrid -- /path/to/cinemagrid-cli mcp --demo

# 2. Or bridge Claude into your live desktop session
claude mcp add cinemagrid-live -- /path/to/cinemagrid-cli --bridge 127.0.0.1:9876

# 3. Then just ask: "trim the demo timeline to 10 seconds and export"
# Drive the engine from any Python script (JSONL commands on stdin)
import json, subprocess

cmd = {"id": "tts.create", "params": {
    "text": "Hello from a Python agent", "voice": "basic-female",
    "seconds": 1.0, "track": "Audio 3", "dir": "narrations"}}
subprocess.run(["cinemagrid-cli", "run", "-", "--save-as", "out.fcproj"],
               input=json.dumps(cmd) + "
", text=True)

Connect Claude Code

Add the CinemaGrid MCP server to your Claude configuration with one command:

claude mcp add cinemagrid-headless -- /path/to/cinemagrid-cli mcp --demo

Your AI assistant can now inspect sequences, cut footage, synthesize voiceovers, apply color grades, and render exports automatically.
